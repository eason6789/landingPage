# 第二大脑自动化

## 理念

让 AI Agent 自动化摄入、整理和检索知识，构建"第二大脑"。

## 核心流程

1. **摄入** — 用户发送内容（链接/笔记/想法）
2. **提取** — AI 提取关键概念和实体
3. **存储** — 保存到知识库，添加交叉引用
4. **检索** — 用户问问题时从知识库回答

## 使用方式

### 摄入资料
```
帮我把这个摄入到 wiki：<粘贴链接或内容>
```

### 问问题
```
根据 wiki，帮我整理一下关于 [主题] 的内容
```

### 维护检查
```
帮我 lint 一下 wiki
```

## 目录结构

```
wiki/
├── SCHEMA.md          # 规范
├── index.md          # 总览
├── log.md            # 日志
├── raw/              # 原始资料
├── entities/         # 实体
├── concepts/         # 概念
├── comparisons/      # 对比
└── queries/         # 问答
```

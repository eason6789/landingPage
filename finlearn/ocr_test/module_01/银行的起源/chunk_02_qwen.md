### 资产业务 - 贷款
银行在有了资金、且通过负债业务获取的资金以后，这部分资金要产生收益，那么就需要进行资产运作。

资产业务中最重要的是 **贷款业务**。

除贷款业务以外，银行也能会涉及到的是 **资金类业务（treasury）** ，即银行将自己所有的资金，用于同业务、债券买卖等，来获取收益。

同时，资金类业务也会涉及到各种金融管理，如汇率风险、利率风险等。

最后，银行在其他同业的存款、包括中央银行准备金，也属于银行自身资产。

#### 1. 贷款业务
贷款业务是银行作为信用中介的核心所在，也是银行可以创造货币的原因。

| 贷款业务分类 |
|--------------|
| 信用贷款     |
| 抵押贷款     |
| 保证贷款     |
| 票据贴现     |

- 信用贷款：无担保，风险高
- 抵押贷款：用抵押物作担保，如房产、车辆等
- 保证贷款：由第三方提供担保
- 票据贴现：以未到期票据为标的，向银行申请贴现

按客户分类：个人贷款 / 对公贷款 / 内部转借

### 负债与资产的平衡管理

#### 存款业务的衡量因素
衡量一个银行存款业务的因素：存款规模 / 存款期限 / 利率高低 等

**如果在做银行行长，你会对存款部门设定什么 KPI？**

1. 存款规模是不是越高越好？
2. 存款期限要如何评价？活期和定期哪个好？
3. 存款的利率高低？什么是正常合理的利率区间？

**需要综合考虑 存贷比（贷款 / 存款比例）LDR**

#### 贷款业务的衡量因素
衡量银行贷款业务的因素：贷款规模 / 收益率 / 贷款质量 / 贷款成本 等

**如果你是银行行长，你会对贷款部门设定什么 KPI？**

1. 贷款规模是不是越高越好？可以无限放贷吗？
2. 什么样的人更了解他偿债能力？什么人贷款不偿债？
3. 贷款的利率高低？什么是正常合理的利率区间，放出去的贷款利率一定越高越好吗？

#### 关于 FTP 定价
银行对于存贷款的定价主要采用内部资金转移定价（funding transfer pricing, FTP），法对存款进行定价。通过 FTP 利率，商业银行的管理人员可以比较出各机构银行的净利息收益率在各个业务单元中进行划分，从而对商业银行各业务单元的创利绩效进行有效的评估。

```
存款 → FTP → 贷款
```

### 中间业务

中间业务又叫表外业务，是指不构成银行表内资产、表内负债，但能给银行带来收入的业务。

中间业务的流程如下：
- 客户选择支付方式
- 银行处理交易
- 与清算系统对接
- 最终完成支付

**支付汇款和银行卡支付有什么差异？**
**重点在其中代表的结算体系不同**

**支付结算流程图**

```
客户选择支付方式
        ↓
    银行处理交易
        ↓
    与清算系统对接
        ↓
    清算中心处理
        ↓
    完成支付
```

**支持的支付方式**
- 本地支付（如支付宝、微信）
- 国际卡组织（Visa、Mastercard）
- 电子钱包（Apple Pay、Google Pay）
- 银行自有App

**天星银行账户**
- 银行自有账户
- 参与各类支付结算体系（FIPS/PSD2/SWIFT）
- 各类银行业务均在银行门户进行

**天星银行卡**
- 银行参与多个卡组织发行
- 参与卡组织的清算体系（Visa/MasterCard）
- 主要解决消费支付场景

### 香港银行的监管体系

**香港金融管理局（HKMA, HONG KONG MONETARY AUTHORITY）**，是香港银行行业监管机构的核心，同时也承担了在香港制定货币政策的中央银行的职能。

金融局既认可和监管在香港经营的银行及非银行接受存款业务。

香港银行的存款机构有三级制度。

| 存款机构类型 | 持牌银行 | 有限制持牌银行 | 接受存款公司 | 无存款业务机构 |
|--------------|----------|----------------|---------------|----------------|
| 业务 | - 经营本地及离岸银行业务<br>- 能够公司注册或收购银行的持股<br>- 支付定额费用可签发旅行支票<br>- 不受限制地使用“银行”之名 | - 主要从事私人银行业务和信托活动业务<br>- 只能为公司签发以上凭证和银行支票 | - 主要以提供代客服务和代理业务为主<br>- 不能接受公众存款<br>- 可接受10万港元以上、最高存款额度为50万港元 | - 无存款业务 |
| 说明 | - 通常指传统商业银行 | - 通常是私人银行或信托公司 | - 通常是信托公司或财务公司 | - 无存款业务 |

《银行条例》是香港银行业监管的法律基础。

当然，除香港金管局以外，银行在从事具体业务时，还受到其他监管机构的管理，如有证监会 SFC、保险监管局、存款保障委员会等。

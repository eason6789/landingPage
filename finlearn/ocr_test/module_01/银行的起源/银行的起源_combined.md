### 01 商业银行的起源

#### | 商业银行的起源

关于银行的起源，有两种主流的解释，一种是金匠论，一种是汇兑论。这两种论说没有对错，都可以看做是从一个侧面反映银行的发展来源。

##### 1. 金匠的故事

在17世纪的英国，人们当时会把金子换到私密的金匠处作为保管（当时没有纸币，存钱就是存黄金），同时交付一定数额的金子保管费。金匠们为这些商人开具了一张收据证，作为日后取金的依据。

但当越来越多的客户将金子存入金匠后，金匠发现：只要自己不把所有的金子都拿出来，而只是把部分金子交给客户，就可以继续开收据。于是他们开始发行“凭单”——这便是早期的银行票据。

金匠的故事表明：银行的出现是和**储藏及贷款**相关的。

1694年，英格兰银行作为世界上第一家股份制银行在英格兰成立，标志着各国中央银行体制的起源。

##### 2. 山西票号

清代中期（也称清朝同治已后）随着经济的发展和商品流通的加快，原来的货币使用方式已经不能适应形势。山西票号就在这种历史背景下应运而生。

早期主要做的是汇兑买卖，就是你把银子交到它的账上，拿上一张由票号开出的汇票，到别的地方就可以凭此票把银子取出来。而在它开业之前，老百姓出门办事，不是纯粹地走投无路，都得亲自背着沉甸甸的银子上路，既费事又不安全。

票号的故事表明：银行的出现和**汇兑的功能**相关联。

# 金融监管会看什么

商业银行的经营原则，可以抽象概括为：在保证 **安全性** 和 **流动性** 的基础上追求经营利润，并且防范涉及银行的相关金融犯罪。

## 1 安全性

由于银行涉及吸收公众的存款，因此，需要保障吸收存款之后，公众还能拿回本相应存款。  
安全性对存款者是至关重要的，其中 **资本充足率** 和 **杠杆比率** 的指标是其核心考量，即“**风险权重**”，但是银行存在合约的考量指标。

### 资本充足率（Capital Adequacy Ratio,CAR）= 相应类型的资本 / （风险加权资产）（risk-weighted assets），不同级别的资本对风险加权资产的比例要求不一。例如：普通股、优先股、银行持有的风险资产越多，可能产生的可能性越大，那么就需要更多的资本，来覆盖潜在的亏损，以确保银行能正常运营。

| 风险加权资产 | 比例 |
| --- | --- |
| 一般贷款类 - 信用风险 (CCY) | 100% |
| 一般贷款类 - 信用风险 (CCY) | 50% |
| 一般贷款类 - 信用风险 (CCY) | 20% |
| 一般贷款类 - 信用风险 (CCY) | 0% |

### 杠杆比率（leverage ratio）：衡量不同的衡量方式，核心的考量为银行的资本占其所有资产的比例，如一级资本/未加权的表内外资产总计。  
巴塞尔协议已将该协议 III 提出要求 3%。

# 金融监管会看什么

商业银行的经营原则，可以抽象概括为：在保证 **安全性** 和 **流动性** 的基础上追求经营利润，并且防范涉及银行的相关金融犯罪。

## 2 流动性

流动性同样是衡量银行的一个关键指标，简单来说，当银行的客户需要拿出钱的时候，银行要有相关的偿付能力。  
在极端条件下，虽然银行的资产可能账面价值很高，但如果客户出现集中兑付需求（发生挤兑），但银行短期没有足够资金，也可能让银行出现倒闭风险。  
流动性的考量指标较多，这里我们仅展示并介绍 **流动性覆盖比率** 的指标。

### 流动性覆盖比率

| 流动性覆盖比率 | LCR |
| --- | --- |
| 可用稳定资金（A） | 100% |
| 所需稳定资金（B） | 100% |
| LCR = A/B | ≥ 100% |

### 法规相关指标，主要参考的是：**流动性覆盖比率**（Liquidity Coverage Ratio, LCR）和 **流动性维持比率**（Liquidity Maintenance Ratio）

#### 2.1 流动性覆盖比率（LCR）
- **LCR** = 可用稳定资金 / 所需稳定资金
- **可用稳定资金** = 短期优质流动性资产 + 其他合格流动性资产
- **所需稳定资金** = 预计未来30天内净现金流出
- **LCR ≥ 100%**

#### 2.2 LMR 与资产负债结构（简化的示意图）
- **LMR** = 可用稳定资金 / 所需稳定资金
- **LMR ≥ 100%**
- **LMR < 100%** → 存在流动性风险

# 防范金融犯罪——反洗钱及反欺诈

除银行自身的业务安全稳定运行外，监管还会考察银行在防范金融犯罪（洗钱和诈骗等）上是否做的足够充分。

### 洗钱：不法分子利用各种合法或非法手段，掩饰或隐瞒资金来源，逃避法律监管，将非法所得的资金通过合法渠道进行转移。

**洗钱三阶段：**
1. **放置（Placement）**：将非法资金存入金融机构。
2. **离析（Layering）**：通过复杂的交易网络隐藏资金来源。
3. **整合（Integration）**：使资金看起来合法，重新进入经济体系。

### 反洗钱系统主要做什么？
- **KYC（Know Your Customer）**：客户身份识别，验证客户身份信息。
- **CDD（Customer Due Diligence）**：客户尽职调查，评估客户风险等级。
- **TML（Transaction Monitoring）**：交易监控，监测异常交易行为。

### 主要的三种方法：
1. **名称检查（Name Check）**：检查客户姓名是否在国际制裁名单上。
2. **SC（SWIFT Check）**：检查交易对手是否在国际制裁名单上。
3. **TML（Transaction Monitoring）**：实时监控交易，识别可疑行为。

# 银行报表分析 – ZA bank 利润表

除了资产负债表，监管披露报表以外，从公开披露的财务报表当中，我们能窥探一家银行靠什么挣钱？主要收入是什么？

## 收入来源

### 利息收入
- **贷款利息收入**：来自向客户提供贷款所产生的利息。
- **投资收益**：来自持有债券、票据等金融工具的利息收入。

### 非利息收入
- **手续费收入**：包括账户管理费、转账手续费、信用卡年费等。
- **其他收入**：如咨询服务费、托管服务费等。

### 成本构成
- **利息支出**：支付给存款人的利息。
- **营业费用**：包括员工薪酬、租金、IT支出等。

### 利润结构图

```
总收入
├── 利息收入
│   ├── 贷款利息收入
│   └── 投资收益
└── 非利息收入
    ├── 手续费收入
    └── 其他收入

总成本
├── 利息支出
└── 营业费用
    ├── 员工薪酬
    ├── 租金
    ├── IT支出
    └── 其他费用
```

### 净利润计算

```
净利润 = 总收入 - 总成本
       = (利息收入 + 非利息收入) - (利息支出 + 营业费用)
       = (6,200 + 3,200) - (1,550 + 3,100)
       = 9,400 - 4,650
       = 4,750
```

### 关键比率

| 比率 | 计算公式 | 数值 |
| --- | --- | --- |
| 净利息收益率（NIM） | (净利息收入 / 总生息资产) × 100% | 3.5% |
| 成本收入比 | (营业费用 / 总收入) × 100% | 40% |
| 净利润率 | (净利润 / 总收入) × 100% | 62.4% |

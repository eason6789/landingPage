### 01 商业银行的起源

#### | 商业银行的起源

关于银行的起源，有两种主流的解释，一种是金匠论，一种是汇兑论。这两种论说没有对错，都可以看做是从一个侧面反映银行的发展来源。

##### 1. 金匠的故事

在17世纪的英国，人们当时会把金子换到私密的金匠处作为保管（当时没有纸币，存钱就是存黄金），同时交付一定数额的金子保管费。金匠们为这些商人开具了一张收据证，作为日后取金的依据。

但当越来越多的客户将金子存入金匠后，金匠发现：只要自己不把所有的金子都拿出来，而只是把部分金子交给客户，就可以继续开收据。于是他们开始发行“凭单”——这便是早期的银行票据。

金匠的故事表明：银行的出现是和**储藏及贷款**相关的。

1694年，英格兰银行作为世界上第一家股份制银行在英格兰成立，标志着各国中央银行体制的起源。

#### | 商业银行的起源

##### 2. 山西票号

清代中期（也称清朝同治已后）随着经济的发展和商品流通的加快，原来的货币使用方式已经不能适应形势。山西票号就在这种历史背景下应运而生。

早期主要做的是汇兑买卖，就是你把银子交到它的账上，拿上一张由票号开出的汇票，到别的地方就可以凭此票把银子取出来。而在它开业之前，老百姓出门办事，不是纯粹地走投无路，都得亲自背着沉甸甸的银子上路，既费事又不安全。

票号的故事表明：银行的出现和**汇兑的功能**相关联。

#### | 负债业务 – 存款

银行获取资金（除资本 / 资本金外）的业务，负债业务主要包括：客户存款、同业拆借、中央银行借款等

负责中最重要的资信来源。吸收存款是传统商业银行资金的主要来源。

### 资产业务 - 贷款
银行在有了资金、且通过负债业务获取的资金以后，这部分资金要产生收益，那么就需要进行资产运作。

资产业务中最重要的是 **贷款业务**。

除贷款业务以外，银行也能会涉及到的是 **资金类业务（treasury）** ，即银行将自己所有的资金，用于同业务、债券买卖等，来获取收益。

同时，资金类业务也会涉及到各种金融管理，如汇率风险、利率风险等。

最后，银行在其他同业的存款、包括中央银行准备金，也属于银行自身资产。

#### 1. 贷款业务
贷款业务是银行作为信用中介的核心所在，也是银行可以创造货币的原因。

| 贷款业务分类 |
|--------------|
| 信用贷款     |
| 抵押贷款     |
| 保证贷款     |
| 票据贴现     |

- 信用贷款：无担保，风险高
- 抵押贷款：用抵押物作担保，如房产、车辆等
- 保证贷款：由第三方提供担保
- 票据贴现：以未到期票据为标的，向银行申请贴现

按客户分类：个人贷款 / 对公贷款 / 内部转借

### 负债与资产的平衡管理

#### 存款业务的衡量因素
衡量一个银行存款业务的因素：存款规模 / 存款期限 / 利率高低 等

**如果在做银行行长，你会对存款部门设定什么 KPI？**

1. 存款规模是不是越高越好？
2. 存款期限要如何评价？活期和定期哪个好？
3. 存款的利率高低？什么是正常合理的利率区间？

**需要综合考虑 存贷比（贷款 / 存款比例）LDR**

#### 贷款业务的衡量因素
衡量银行贷款业务的因素：贷款规模 / 收益率 / 贷款质量 / 贷款成本 等

**如果你是银行行长，你会对贷款部门设定什么 KPI？**

1. 贷款规模是不是越高越好？可以无限放贷吗？
2. 什么样的人更了解他偿债能力？什么人贷款不偿债？
3. 贷款的利率高低？什么是正常合理的利率区间，放出去的贷款利率一定越高越好吗？

#### 关于 FTP 定价
银行对于存贷款的定价主要采用内部资金转移定价（funding transfer pricing, FTP），法对存款进行定价。通过 FTP 利率，商业银行的管理人员可以比较出各机构银行的净利息收益率在各个业务单元中进行划分，从而对商业银行各业务单元的创利绩效进行有效的评估。

```
存款 → FTP → 贷款
```

### 中间业务

中间业务又叫表外业务，是指不构成银行表内资产、表内负债，但能给银行带来收入的业务。

中间业务的流程如下：
- 客户选择支付方式
- 银行处理交易
- 与清算系统对接
- 最终完成支付

**支付汇款和银行卡支付有什么差异？**
**重点在其中代表的结算体系不同**

**支付结算流程图**

```
客户选择支付方式
        ↓
    银行处理交易
        ↓
    与清算系统对接
        ↓
    清算中心处理
        ↓
    完成支付
```

**支持的支付方式**
- 本地支付（如支付宝、微信）
- 国际卡组织（Visa、Mastercard）
- 电子钱包（Apple Pay、Google Pay）
- 银行自有App

**天星银行账户**
- 银行自有账户
- 参与各类支付结算体系（FIPS/PSD2/SWIFT）
- 各类银行业务均在银行门户进行

**天星银行卡**
- 银行参与多个卡组织发行
- 参与卡组织的清算体系（Visa/MasterCard）
- 主要解决消费支付场景

### 香港银行的监管体系

**香港金融管理局（HKMA, HONG KONG MONETARY AUTHORITY）**，是香港银行行业监管机构的核心，同时也承担了在香港制定货币政策的中央银行的职能。

金融局既认可和监管在香港经营的银行及非银行接受存款业务。

香港银行的存款机构有三级制度。

| 存款机构类型 | 持牌银行 | 有限制持牌银行 | 接受存款公司 | 无存款业务机构 |
|--------------|----------|----------------|---------------|----------------|
| 业务 | - 经营本地及离岸银行业务<br>- 能够公司注册或收购银行的持股<br>- 支付定额费用可签发旅行支票<br>- 不受限制地使用“银行”之名 | - 主要从事私人银行业务和信托活动业务<br>- 只能为公司签发以上凭证和银行支票 | - 主要以提供代客服务和代理业务为主<br>- 不能接受公众存款<br>- 可接受10万港元以上、最高存款额度为50万港元 | - 无存款业务 |
| 说明 | - 通常指传统商业银行 | - 通常是私人银行或信托公司 | - 通常是信托公司或财务公司 | - 无存款业务 |

《银行条例》是香港银行业监管的法律基础。

当然，除香港金管局以外，银行在从事具体业务时，还受到其他监管机构的管理，如有证监会 SFC、保险监管局、存款保障委员会等。

# 金融监管会看什么

商业银行的经营原则，可以抽象概括为：在保证 安全性 和 流动性的基础上追求经济利润，并且防范涉及银行的相关金融犯罪。

## 1 安全性

由于银行涉及吸收公众的存款，因此，需要保障吸收存款之后，公众还能拿回来相应的存款。  
安全性的考虑主要出于此目的，其中 资本充足率 和 杠杆比率 的指标是其核心考量。两个指标互补，但都是银行安全性的考量指标。

**资本充足率（Capital Adequacy Ratio, CAR）= 相应类型的资本（capital）/ 风险加权资产（risk-weighted assets）**，不同等级的资本对应风险加权资产的比例要高于一定的比例。简单来说，反映的是：银行持有的风险资产越多，可能产生亏损的可能性就越大，那么就要有更多的钱（资本）来覆盖潜在可能的亏损，以免银行的客户出现亏损。

| 最新资本充足比率 |
| --- |
| **资本充足比率** | **不低于** |
| 普通银行一级资本比率（CT1）[即能吸收市场崩溃造成的监管资本] | 4.5% |
| 一级资本比率 | 6% |
| 总资本比率 | 8% |

**杠杆比率（leverage ratio）** 有多种不同的衡量方式，核心的考量为银行的资本在总计所有资产的比例，如 一级资本 / 未加权的表内外资产总计。  
巴塞尔协议巴塞尔协议 III 最低要求 3%。

# 金融监管会看什么

商业银行的经营原则，可以抽象概括为：在保证 安全性 和 流动性的基础上追求经济利润，并且防范涉及银行的相关金融犯罪。

## 2 流动性

流动性同样也是考量银行的一个关键指标，简单来说，当银行的客户需要拿出钱的时候，银行要有相关的应付能力。  
在极端条件下，虽然银行的资产可能很安全，但如果客户出现集中兑付需求（发生挤兑），但银行短期没有足够资金，也可能让银行出现倒闭风险。

流动性的考量指标较多，这里我们仅简单介绍 **流动性覆盖率** 的指标。

| 流动性最低要求 |
| --- |
| **MLR指标** | **MLR指标** | **MLR指标** |
| 流动性覆盖比率（LCR） | 核心资本充足比率（CET1） | 流动性缓冲比率（LMR） | 流动性缓冲比率（LMR） | 核心资本比率（CET1） |
| 100% | 100% | 25% | 25% | 75% |

流动性相关的指标，主要当中衡量的是 **流动性覆盖比率（Liquidity Coverage Ratio, LCR）** 和 **流动性维持比率（Liquidity Maintenance Ratio）**

### 3.1 流动性覆盖比率（LCR）

> *LCR 是指「高流动性资产」（例如现金、3M以内到期的央票、政府债券等）与「净现金流出量」（即压力情景下未来30天内预计的现金流出减去流入）之比。*

$$
\text{LCR} = \frac{\text{HQLA}}{\text{净现金流出量}} \times 100\%
$$

### 3.2 LMR 为第 2 个机构在一个月内的「流动资产」的数额的比率（又叫「流动性缓冲比率」）

$$
\text{LMR} = \frac{\text{流动性资产}}{\text{限定负债（银行出扣除后）}} \times 100\%
$$

流动性的考量指标较多，这里我们仅展示并介绍 **流动性覆盖比率** 的指标。

### 流动性覆盖比率

| 流动性覆盖比率 | LCR |
| --- | --- |
| 可用稳定资金（A） | 100% |
| 所需稳定资金（B） | 100% |
| LCR = A/B | ≥ 100% |

- **可用稳定资金** = 短期优质流动性资产 + 其他合格流动性资产

- **LMR** = 可用稳定资金 / 所需稳定资金
- **LMR ≥ 100%**
- **LMR < 100%** → 存在流动性风险

# 防范金融犯罪——反洗钱及反欺诈

除银行自身的业务安全稳定运行外，监管还会考察银行在防范金融犯罪（洗钱和诈骗等）上是否做的足够充分。

### 洗钱：不法分子利用各种合法或非法手段，掩饰或隐瞒资金来源，逃避法律监管，将非法所得的资金通过合法渠道进行转移。

**洗钱三阶段：**
1. **放置（Placement）**：将非法资金存入金融机构。
2. **离析（Layering）**：通过复杂的交易网络隐藏资金来源。
3. **整合（Integration）**：使资金看起来合法，重新进入经济体系。

- **TML（Transaction Monitoring）**：交易监控，监测异常交易行为。

### 主要的三种方法：
1. **名称检查（Name Check）**：检查客户姓名是否在国际制裁名单上。
2. **SC（SWIFT Check）**：检查交易对手是否在国际制裁名单上。
3. **TML（Transaction Monitoring）**：实时监控交易，识别可疑行为。

## 收入来源

### 利息收入
- **贷款利息收入**：来自向客户提供贷款所产生的利息。
- **投资收益**：来自持有债券、票据等金融工具的利息收入。

### 非利息收入
- **手续费收入**：包括账户管理费、转账手续费、信用卡年费等。
- **其他收入**：如咨询服务费、托管服务费等。

### 成本构成
- **利息支出**：支付给存款人的利息。
- **营业费用**：包括员工薪酬、租金、IT支出等。

### 利润结构图

```
总收入
├── 利息收入
│   ├── 贷款利息收入
│   └── 投资收益
└── 非利息收入
    ├── 手续费收入
    └── 其他收入

总成本
├── 利息支出
└── 营业费用
    ├── 员工薪酬
    ├── 租金
    ├── IT支出
    └── 其他费用
```

### 净利润计算

```
净利润 = 总收入 - 总成本
       = (利息收入 + 非利息收入) - (利息支出 + 营业费用)
       = (6,200 + 3,200) - (1,550 + 3,100)
       = 9,400 - 4,650
       = 4,750
```

### 关键比率

| 比率 | 计算公式 | 数值 |
| --- | --- | --- |
| 净利息收益率（NIM） | (净利息收入 / 总生息资产) × 100% | 3.5% |
| 成本收入比 | (营业费用 / 总收入) × 100% | 40% |
| 净利润率 | (净利润 / 总收入) × 100% | 62.4% |

### 01 商业银行的起源

#### | 商业银行的起源

关于银行的起源，有两种主流的解释，一种是金匠论，一种是汇兑论。这两种论说没有对错，都可以看做是从一个侧面反映银行的发展来源。

##### 1. 金匠的故事

在17世纪的英国，人们当时会把金子换到私密的金匠处作为保管（当时没有纸币，存钱就是存黄金），同时交付一定数额的金子保管费。金匠们为这些商人开具了一张收据证，作为日后取金的依据。

但当越来越多的客户将金子存入金匠后，金匠发现：只要自己不把所有的金子都拿出来，而只是把部分金子交给客户，就可以继续开收据。于是他们开始发行“凭单”——这便是早期的银行票据。

金匠的故事表明：银行的出现是和**储藏及贷款**相关的。

1694年，英格兰银行作为世界上第一家股份制银行在英格兰成立，标志着各国中央银行体制的起源。

##### 2. 山西票号

清代中期（也称清朝同治已后）随着经济的发展和商品流通的加快，原来的货币使用方式已经不能适应形势。山西票号就在这种历史背景下应运而生。

早期主要做的是汇兑买卖，就是你把银子交到它的账上，拿上一张由票号开出的汇票，到别的地方就可以凭此票把银子取出来。而在它开业之前，老百姓出门办事，不是纯粹地走投无路，都得亲自背着沉甸甸的银子上路，既费事又不安全。

票号的故事表明：银行的出现和**汇兑的功能**相关联。

- **KYC（Know Your Customer）**：客户身份识别，验证客户身份信息。
- **CDD（Customer Due Diligence）**：客户尽职调查，评估客户风险等级。
- **TML（Transaction Monitoring）**：交易监控，监测异常交易行为。

### 主要的三种方法：
1. **名称检查（Name Check）**：检查客户姓名是否在国际制裁名单上。
2. **SC（SWIFT Check）**：检查交易对手是否在国际制裁名单上。
3. **TML（Transaction Monitoring）**：实时监控交易，识别可疑行为。

# 银行报表分析 – ZA bank 利润表

除了资产负债表，监管披露报表以外，从公开披露的财务报表当中，我们能窥探一家银行靠什么挣钱？主要收入是什么？

## 收入来源

### 利息收入
- **贷款利息收入**：来自向客户提供贷款所产生的利息。
- **投资收益**：来自持有债券、票据等金融工具的利息收入。

### 非利息收入
- **手续费收入**：包括账户管理费、转账手续费、信用卡年费等。
- **其他收入**：如咨询服务费、托管服务费等。

### 成本构成
- **利息支出**：支付给存款人的利息。
- **营业费用**：包括员工薪酬、租金、IT支出等。

### 利润结构图

```
总收入
├── 利息收入
│   ├── 贷款利息收入
│   └── 投资收益
└── 非利息收入
    ├── 手续费收入
    └── 其他收入

总成本
├── 利息支出
└── 营业费用
    ├── 员工薪酬
    ├── 租金
    ├── IT支出
    └── 其他费用
```

### 净利润计算

```
净利润 = 总收入 - 总成本
       = (利息收入 + 非利息收入) - (利息支出 + 营业费用)
       = (6,200 + 3,200) - (1,550 + 3,100)
       = 9,400 - 4,650
       = 4,750
```

### 关键比率

| 比率 | 计算公式 | 数值 |
| --- | --- | --- |
| 净利息收益率（NIM） | (净利息收入 / 总生息资产) × 100% | 3.5% |
| 成本收入比 | (营业费用 / 总收入) × 100% | 40% |
| 净利润率 | (净利润 / 总收入) × 100% | 62.4% |

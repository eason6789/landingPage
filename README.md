<h2 id="english">陀螺的创想世界 (Eason's Creative World)</h2>

Personal portfolio landing page featuring a pixel-art retro game aesthetic. Scroll-snapped full-page layout showcasing tools & platforms, demos, mini programs, games, and open-source projects.

### Features

- **Pixel Art Retro Aesthetic** -- Silkscreen & Share Tech Mono fonts, pixelated borders, grid-pattern background, glitch animations
- **Sidebar Navigation** -- Avatar, name/bio, and section jump links with pixel-art styling
- **Project Showcase** -- Grid card layout with hover effects, HOT/NEW badges, QR code overlays
- **4 Content Sections** -- Tools & Platforms, Demos, Mini Programs & Games, Open Source Projects
- **Contact Page** -- Social links with hover QR code tooltips (WeChat, email, GitHub, etc.)
- **Mobile Responsive** -- Adapts layout for small screens with hamburger menu
- **Sub-projects** -- Serves `/claw/`, `/finlearn/`, `/video-feed/`, `/wiki/`, `/games.html`, `/tools.html`

### Tech Stack

- Frontend: Vanilla HTML/CSS/JS, no frameworks
- Fonts: Google Fonts (Silkscreen, DotGothic16, Share Tech Mono, ZCOOL QingKe HuangYou)

### Local Development

1. Open `index.html` directly in a browser
2. Or start a local static server: `python3 -m http.server 8080` and open `http://localhost:8080`

### Deployment

See [DEPLOY.md](DEPLOY.md)

<h2 id="chinese">陀螺的创想世界 (Eason's Creative World)</h2>

个人作品集落地页，像素风复古游戏美学。全页滚动布局展示 工具与平台、Demo、小程序、游戏和开源项目。

### 功能特性

- **像素复古风** -- Silkscreen & Share Tech Mono 字体，像素化边框，网格背景，故障动画
- **侧边栏导航** -- 头像、简介、分区跳转链接，像素风格设计
- **项目展示** -- 网格卡片布局，悬停特效，HOT/NEW 徽章，二维码浮层
- **4 个内容分区** -- 工具与平台、Demo、小程序 & 游戏、开源项目
- **联系页** -- 社交链接，悬停显示二维码（微信、邮箱、GitHub 等）
- **移动端适配** -- 自适应小屏布局，汉堡菜单
- **子项目** -- 托管 `/claw/`、`/finlearn/`、`/video-feed/`、`/wiki/`、`/games.html`、`/tools.html`

### 技术栈

- 前端：原生 HTML/CSS/JS，无框架
- 字体：Google Fonts (Silkscreen, DotGothic16, Share Tech Mono, ZCOOL QingKe HuangYou)

### 本地开发

1. 直接用浏览器打开 `index.html`
2. 或启动本地静态服务器：`python3 -m http.server 8080`，访问 `http://localhost:8080`

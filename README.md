# 陀螺的创想世界 (Eason's Creative World)

Personal portfolio landing page featuring a pixel-art retro game aesthetic. Scroll-snapped full-page layout showcasing AI tools, demos, mini programs, games, and open-source projects.

## Features

- **Pixel Art Retro Aesthetic** -- Press Start 2P & VT323 fonts, pixelated borders, grid-pattern background, glitch animations
- **Sidebar Navigation** -- Avatar, name/bio, and section jump links with pixel-art styling
- **Project Showcase** -- Grid card layout with hover effects, HOT/NEW badges, QR code overlays
- **4 Content Sections** -- AI Tools, Demos, Mini Programs & Games, Open Source Projects
- **Contact Page** -- Social links with hover QR code tooltips (WeChat, email, GitHub, etc.)
- **Mobile Responsive** -- Adapts layout for small screens with hamburger menu
- **Sub-projects** -- Serves `/claw/`, `/finlearn/`, `/video-feed/`, `/wiki/`, `/games.html`, `/tools.html`

## Tech Stack

- Frontend: Vanilla HTML/CSS/JS, no frameworks
- Fonts: Google Fonts (Press Start 2P, VT323, Silkscreen, DotGothic16, ZCOOL QingKe HuangYou)

## Local Development

1. Open `index.html` directly in a browser
2. Or start a local static server: `python3 -m http.server 8080` and open `http://localhost:8080`
